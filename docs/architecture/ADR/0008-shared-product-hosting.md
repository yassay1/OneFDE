# 公司网站与客户产品共用阿里云服务器

状态：历史方向，已被同日用户最新要求及[ADR0009](0009-single-ecs-mvp.md)取代。以下工程物理另机/内部工作台托管未定的表述仅保留决策历史，不能作为当前MVP实施约束；未购买或部署。

## 决定与理由

先在本地开发和检查，后续用一台阿里云Linux服务器托管公司网站及客户产品，减少首期多套托管环境的维护。产品保持独立版本、站点和运行配置；“独立发布”不要求每个产品独占服务器。

Coding Agent的Worker、Agent Server和任意代码执行环境与正式托管服务器分开；本地执行沿用[ADR0007](0007-local-wsl-development.md)，正式工程执行仍按[ADR0003](0003-execution-validation.md)。只通过受控发布交付已确认版本。

## 边界与重访

公司网站和客户产品可同机，不表示自动共享客户数据或授予访问内部OneFDE工作台的权限。内部控制后端/数据库目前保留本地；未来托管位置另行确定。本确认不启动公司网站、客户产品或工作台前端开发。

单机共享资源和故障范围，不承诺容量或高可用；出现实际资源争用、客户隔离要求或可用性要求时，再评估升级/拆分。服务器地域/规格/费用、域名与站点划分、维护责任和交付期限仍待发布前确认。

拓扑、发布条件和维护边界以[部署设计](../../operations/deployment.md)为唯一详细来源；实施顺序见[实施计划](../../development/implementation-plan.md)。
