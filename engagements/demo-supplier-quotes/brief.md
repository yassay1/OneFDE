# 供应商报价比较模拟演示

项目 ID 为 `demo-supplier-quotes`。状态为需求准备，尚未执行开发、构建或部署。资料类型为模拟演示；没有真实客户、真实报价文件、使用反馈或已验证的经营收益。

平台范围见 [PRD](../../docs/product/PRD.md)，本记录负责首个具体案例的规则、样例与交付证据。

## 目标与来源

以水果店老板整理多家供应商报价的场景，验证从需求诊断、任务拆分、工程执行到部署访问和资产复用的链路。

场景来自[产品定义](../../docs/product/product-definition.md)的首个案例。2026 年 11 月 3 日，创始人在本次文档工作中确认“先验证最小比较流程”：商品、等级和规格明确一致且单位可换算时比较；信息不足标记待核对；第一轮不计算运费、起订量和送货条件。

## 已确认的第一轮边界

| 编号 | 规则或范围 | 结果要求 |
| --- | --- | --- |
| R01 | 商品、等级和规格明确一致才可比较 | 不因名称相似或报价数字较低，就将不同口径强行比较 |
| R02 | 比较单位须相同或能够依据已确认规则换算 | 信息不足或无法确认换算时标记待核对，不由模型补净重 |
| R03 | 缺失商品/规格/计量所需信息 | 展示待核对项与缺失原因，不给出该项最低价结论 |
| R04 | 第一轮不计算运费、起订量和送货条件 | 展示结果时说明未计入这些条件，不声称是总采购成本最优 |
| R05 | 不自动采购或替老板决定供应商 | 展示约定口径下的比较结果，最终采购由人决定 |

输入为 Excel/CSV，目标输出为可比较报价、待核对或不可比较项及原因，并提供必要结果导出。具体格式兼容、字段与导出形式尚待细化。

## 模拟样例提案

以下仅为后续准备样例的提案，不是已执行测试或真实客户业务规则。示例 A/B 是虚构供应商，金额是为检查比较结果而设的数值。

| 样例 | 输入构造 | 拟检查的结果 |
| --- | --- | --- |
| S01 同口径 | 已明确同商品、同等级、同规格，两家均按元/公斤报价，A 为 8、B 为 7.5 | B 的单位报价较低；不推导综合采购结论 |
| S02 规格缺失 | 同名盒装商品，均未提供净重 | 标记待核对，不比较盒价来推断单位最低价 |
| S03 规格或等级不同 | 名称相同但等级或包装规格明确不同 | 保持不同口径分组，不直接生成两者最低价结论 |
| S04 单位换算 | 按后续确认的换算表构造等价计量 | 转换过程与单位价格可核对；换算表未确认前不写预期数值 |
| S05 混合文件 | 一份输入同时包含可比较与待核对项目 | 分别呈现有效结果和原因，不静默丢弃待核对项 |
| S06 第二组需求 | 另造明确标注模拟的报价资料并改变字段或规格组合 | 检索并实际使用首案例的能力，记录适配与重新检查结果 |

真实 Excel/CSV 样例文件尚未创建。S01 的数值和样例覆盖可在阶段 B 细化；S04 需要确认具体单位、换算关系与显示精度。空值、重复报价、相同价格、无效数值、日期等边界也在该阶段明确，不在当前稿中自行决定处理语义。
