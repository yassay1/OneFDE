项目 ID 为 `demo-supplier-quotes`。状态为 **P0 样例已固定；P2 产品 v1.1、样例检查与平台 FDE 控制链已通过**（确定性 Run 回填）；**P4 本地独立 Origin** 为 `http://127.0.0.1:8765`。售后真实模型已运行一次，人工修复归档已验收并通过内部复测。资料类型为模拟演示；没有真实客户、真实报价文件、使用反馈或已验证的经营收益。 [售后验收](#csv-售后回归样例)

## 目标与来源

以水果店老板整理多家供应商报价的场景，验证：**一个模拟报价产品 → 同一 Task 的一次范围内修改 → 第二个模拟项目中的固定版本资产复用**。OneFDE 是创始人管理交付的内部产品；门店使用独立交付的软件。

场景来自[产品定义](../../docs/product/product-definition.md)的首个案例。2026 年 11 月 3 日确认最小比较边界；2026 年 11 月 4 日确认黑客松参赛主线与 CSV 优先；同日推进 P0，落下最小字段与样例文件。

## 已确认的第一轮边界

| 编号 | 规则或范围 | 结果要求 |
| --- | --- | --- |
| R01 | 商品、等级和规格明确一致才可比较 | 不因名称相似或报价数字较低，就将不同口径强行比较 |
| R02 | 比较单位须相同或能够依据已确认规则换算 | 信息不足或无法确认换算时标记待核对，不由模型补净重 |
| R03 | 缺失商品/规格/计量所需信息 | 展示待核对项与缺失原因，不给出该项最低价结论 |
| R04 | 第一轮不计算运费、起订量和送货条件 | 展示结果时说明未计入这些条件，不声称是总采购成本最优 |
| R05 | 不自动采购或替老板决定供应商 | 展示约定口径下的比较结果，最终采购由人决定 |

**CSV 优先**做最小演示；Excel 扩展后置。原 Excel/CSV 目标不删除。价格计算、过滤和导出由普通程序完成。

## P0 最小字段约定（已固定用于样例）

黑客松最小演示使用下列 CSV 列；顺序与拼写与样例文件一致。映射到内部模型时可改名，但导入须能对应到这些语义。

| 列名 | 含义 | P0 要求 |
| --- | --- | --- |
| `supplier` | 供应商名称 | 必填；样例使用「示例供应商A/B」 |
| `product` | 商品名称 | 必填；同名不等于同口径 |
| `grade` | 等级 | 必填；参与 R01 一致性判断 |
| `spec` | 规格说明 | 必填文本；缺计量信息时在此或 `note` 标明 |
| `unit` | 报价单位 | 必填；P0 可比对仅允许双方均为 `kg` |
| `unit_price` | 该单位下的报价 | 必填数字；P0 按输入小数展示，不另定四舍五入规则 |
| `currency` | 货币 | P0 固定 `CNY`；不做汇率换算 |
| `note` | 备注 | 可空；承载「模拟」标记或缺信息说明 |

**P0 可比条件（可检查）：** `product`、`grade`、`spec`、`unit` 四者均相同，且 `unit=kg`，且 `unit_price` 为有效非负数字。否则进入待核对或不可比，并给出原因；**不得**用盒价推断每公斤更便宜，**不得**跨等级生成单一最低价，**不得**自动选定供应商。

## P0 固定样例与预期

样例文件在 [samples/](samples/README.md)。示例供应商与金额为虚构检查数据。

| 样例 | 输入文件 | 预期结果（验收用） |
| --- | --- | --- |
| S01 同口径 | [s01-same-basis.csv](samples/s01-same-basis.csv) | 两行可比较；示例供应商B 的 `unit_price` 7.5 **低于** A 的 8.0；展示约定口径比较，不给出采购决策或总成本最优 |
| S02 缺净重 | [s02-missing-net-weight.csv](samples/s02-missing-net-weight.csv) | 两行均为待核对（单位为 `box` 且净重未提供）；**不**因 22\<25 宣布 B 更便宜 |
| S03 等级不同 | [s03-different-grade.csv](samples/s03-different-grade.csv) | `grade` 分别为一级/二级，保持不同口径；**不**生成跨等级单一最低价结论 |
| S04 单位换算 | （无文件） | 换算表确认前不写预期数值，不创建误导样例 |
| S05 混合 | [s05-mixed.csv](samples/s05-mixed.csv) | 富士苹果按 S01 可比较；蜜桔按 S02 待核对；香蕉按 S03 不可合并；待核对/不可比项不得静默丢弃 |
| S06 第二组 | （P3 再造） | 检索并实际使用首案例固定资产，记录适配与重新检查 |

限制说明（所有样例共用）：结果须标明未计入运费、起订量、送货条件；最终采购由人决定（R04/R05）。

## CSV 售后回归样例

`S01-unit-price-space` 从 S01 只派生一个尾随 ASCII 空格的 `unit_price ` 表头。修复前 v1.1 对变体报缺列。人工修复对 `unit_price` 表头的边缘 ASCII 空格做归一，变体仍得到 A=8、B=7.5，仅 B 为组内最低。真实缺列仍报错，归一后同名表头明确报冲突，R01–R05 沿用原规则。 [验收记录](../../docs/operations/testing.md#报价自动售后验收)
